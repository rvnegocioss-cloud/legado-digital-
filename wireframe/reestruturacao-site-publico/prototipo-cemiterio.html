Como a hierarquia de navegação funciona aqui

  1. São 3 telas reais neste fluxo: ① lista de cemitérios → ② página de 1 cemitério → ③ página do jazigo. Nunca aparecem juntas — é sempre uma ou outra, igual no site de verdade.
  2. Clicar no card "Cemitério São Pedro" na tela ① abre a ②. Simula o <Link href="/cemiterio/[slug]"> real do Next.js.
  3. Na tela ②, clicar em "Ver o jazigo" no cartão do pino abre a ③ — só aparece porque o jazigo tem 3 memoriais. Com 1 memorial, esse botão não existe e o pino vai direto pro memorial.
  4. A migalha de cada tela volta pro nível de cima (③ → ② → ①). Na ③ o link "Página do Cemitério São Pedro" na lateral também volta pra ②.
  5. A barra lateral esquerda é só o controle deste protótipo (trocar de tela pra revisão) — não existe no site de verdade, é o mesmo recurso do wireframe original do Pedro.
